### Задача №1
Реализовать класс Transformer.
1. Члены класса: переменная - name (имя), методы run (бежать), fire (стрелять), charge
   (зарядиться).
2. В теле каждого метода – соответствующий действию вывод в консоль, например,
   System.out.println(name + “ is running”).
3. Реализован конструктор.

Реализовать дочерние классы Autobot, Decepticon.
1. У обоих классов Autobot и Decepticon появляется свойство teamName (имя
   команды)
2. У обоих классов Autobot и Decepticon появляется свойство eyeColor (значение
   неизменно, у Autobot – синие глаза, у Decepticon - красные).
3. У обоих классов Autobot и Decepticon появляется свойство kindness (значение
   может быть изменено: Autobot – добрые и kindness по умолчанию - true, Decepticon
   – злые и kindness по умолчанию - false).
4. У обоих классов появляется метод transform (трансформироваться). Autobot могут
   превращаться в транспортные средства, Decepticon – наземный и воздушный
   транспорт, оружие, техника. Работу методов показываем выводом в консоль
   сообщения о соответствующей трансформации.
5. Реализованы конструкторы.
   Реализовать сценарий: создать по одному трансформеру, сделать так, чтобы каждый из
   них побежал, пострелял, зарядился, трансформировался.
